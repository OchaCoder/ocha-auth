## 🏷️ Renaming Your Project Folder

If your project folder was named `showcase001`, you can rename it to match your GitHub repo:

```bash
pwd
# /Users/you/Documents/dev/showcase002

cd ..
mv showcase001 ocha-auth
cd ocha-auth
```
